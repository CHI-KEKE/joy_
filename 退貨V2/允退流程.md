## 退貨單狀態檢查

允退前檢查 `ReturnGoodsOrderSlave` 狀態，以下狀態才可允退：

```csharp
case ReturnGoodsOrderSlaveStatusEnum.WaitingToReturnGoods:
case ReturnGoodsOrderSlaveStatusEnum.WaitingToSend:
case ReturnGoodsOrderSlaveStatusEnum.VerifySuccess:
case ReturnGoodsOrderSlaveStatusEnum.SupplierReceived:
case ReturnGoodsOrderSlaveStatusEnum.VerifyFailLost:
case ReturnGoodsOrderSlaveStatusEnum.VerifyFailAbnormalPackage:
case ReturnGoodsOrderSlaveStatusEnum.VerifyFailErrorCode:
case ReturnGoodsOrderSlaveStatusEnum.VerifyFailInvalidCode:
case ReturnGoodsOrderSlaveStatusEnum.StoreReceived:
case ReturnGoodsOrderSlaveStatusEnum.ReturnInTransit:
```

→ 允退後將 `ReturnGoodsOrderSlave_StatusDef` 壓成 `ReturnGoodsProcessing`
