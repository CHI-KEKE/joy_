# 狀態機說明

## 主狀態（BatchUpload_StatusDef）

| 狀態 | 說明 |
|------|------|
| `WaitingToLoadData` | 已完成第一道驗證並建立 BatchUpload NMQ，等待處理 |
| `InLoadData` | NMQ 接到任務，開始初始化準備 LoadExcel |
| `InValidation` | LoadExcel 完成，Wrapper 包好，準備二次驗證 |
| `ReadyToProcess` | 二次驗證成功，準備建立子 NMQ |
| `ValidateFailed` | 二次驗證失敗 |
| `WaitingToProcess` | 主 NMQ 發現 `dataList.Count > 0`（尚有資料待處理） |
| `Finish` | 主 NMQ 發現 `dataList.Count == 0`（全部完成） |
| `ScheduleAbortedWithErrors` | 發現 `BatchUploadData_StatusDef == ValidateFailed`，更新狀態 |
| `InProcess` | 子 Job 已在處理中 |
| `ProcessFailed` | 子 Job 跑完但失敗 |
| `FinishWithError` | 有部分資料失敗 |

<br>

---

## 子資料狀態（BatchUploadData_StatusDef）

| 狀態 | 說明 |
|------|------|
| `ValidateFailed` | 二次驗證失敗 |
| `ProcessFailed` | 子 Job 處理失敗 |

<br>

---

## 狀態流轉圖

```bash
上傳 Excel
  ↓
WaitingToLoadData   ← 第一道驗證通過，NMQ 建立
  ↓
InLoadData          ← NMQ 接到任務，開始 LoadExcel
  ↓
InValidation        ← LoadExcel 完成，進行二次驗證
  ↓
┌─────────────────────────────┐
│ ValidateFailed              │ ← 二次驗證失敗
└─────────────────────────────┘
  ↓（驗證成功）
ReadyToProcess      ← 準備建立子 NMQ Task
  ↓
┌─────────────────┐
│ dataList = 0    │ → Finish
│ dataList > 0    │ → WaitingToProcess
│ 有 ValidateFailed│ → ScheduleAbortedWithErrors
└─────────────────┘
  ↓（WaitingToProcess）
InProcess           ← 子 Job 執行中
  ↓
┌─────────────────┐
│ 成功            │ → Finish（全部完成）
│ 失敗            │ → ProcessFailed / FinishWithError
└─────────────────┘
```
