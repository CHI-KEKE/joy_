## 1. 整體資料邏輯

```bash
使用者上傳 Excel
  → 建立 BatchUpload 紀錄（WaitingToLoadData）
  → 建立主 NMQ Task（BatchUploadProcess）

主 NMQ Task 執行
  → LoadExcel：讀取 Excel，每列建立一筆 BatchUploadData
  → DoValidate：二次驗證
  → 建立子 NMQ Task（每 10 筆 BatchUploadData 一組）

子 NMQ Task 執行
  → 實際處理業務邏輯（呼叫 SCMAPIV2 等）
  → 壓 BatchUploadData 狀態

主 NMQ 持續觸發
  → 直到撈不到 Ready 的 BatchUploadData 為止（Finish）
```

<br>

## 2. CreateBatchTask 入口

```bash
CreateBatchUploadNMQTask（墊一層）
  └── CreateBatchUploadNMQTaskInner（再墊一層）
        ├── CreateBatchUploadEntity（狀態：WaitingToLoadData）
        ├── 產 BatchUploadCode = Csp_GetSequencesCode("BatchUpload_Code")
        ├── 塞 BatchUpload Table
        └── 建立主 NMQ Task（BatchUploadProcess）
```
