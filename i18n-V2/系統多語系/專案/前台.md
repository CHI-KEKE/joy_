

## Global Filter

所有 MVC Request 都會經過

```csharp
 // FilterConfig.cs → App_Start 時執行
 public static void RegisterGlobalFilters(GlobalFilterCollection filters)
 {
     var filterAttributes = DependencyResolver.Current.GetService<FilterAttributeRegister>();
     foreach (var attribute in filterAttributes.GetFilters())
         filters.Add(attribute);  // ← 加入 GlobalFilter
 }
 
 // FilterAttributeRegister.GetFilters()
 detectOfficialAttribute.Order = 1;
 filters.Add(detectOfficialAttribute);  // ← DetectOfficialAttribute 必定在這裡
```

DetectOfficialAttribute 是 Global Filter（Order = 1），MVC 每個 request 在進 Action 之前都會先跑它。

--------------------------------------------------------------------------------------------------------------------------------

## 完整路徑確認

```bash
每一個 MVC 頁面 Request（非 WebAPI）
↓
DetectOfficialAttribute.OnActionExecuting()  ← Global Filter，Order=1
↓
DetectCrossBorderDataForWeb()
↓
語系偵測 → CurrentUICulture = zh-HK
↓
任何用到 Translation 的頁面（含 frontend.sale_page）
→ ELMAH 爆炸
```

--------------------------------------------------------------------------------------------------------------------------------

## 有一個例外

```csharp
 if (configMode != FreeTrialConfigEnum.Mall)
 {
     filters.Add(detectOfficialAttribute);  // ← 一般官網/官網SSO 才加
 }
 else
 {
     // Mall 模式也加，但走不同 instance
 }
```

Mall 模式 也會跑，兩個分支都有加 DetectOfficialAttribute，所以結論是：所有前台 MVC request 全都會走這條語系偵測路徑，沒有例外。
