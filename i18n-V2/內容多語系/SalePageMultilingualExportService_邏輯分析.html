SalePageMultilingualExportService 邏輯分析與鏈路圖

商品頁多語系資料匯出服務 (BatchUpload) — 程式邏輯拆解、資料來源與端到端執行鏈路

1. 服務概觀

類別 NineYi.SCM.Frontend.BLV2.BatchUpload.SalePageMultilingualExportService

SCM\Frontend\BLV2\BatchUpload\SalePageMultilingualExportService.cs

此服務實作 IBatchUploadService，是 NMQV2 批次上傳架構下的「商品頁多語系匯出」功能， 負責將指定商店 (Shop) 底下的商品頁基本資料（預設語系）與非預設語系翻譯內容， 合併輸出成一份 Excel 或 CSV 檔案，提供廠商 / 營運人員下載使用。

核心職責

  • LoadData：解析批次匯出查詢條件，建立 BatchUploadDataEntity 待處理資料列。
  • DoProcess：實際執行匯出流程 — 查詢資料、轉 DataTable、補齊多語系欄位、輸出檔案、更新批次狀態。
  • DoValidate / DoProcessByList：此匯出服務不需要驗證與多筆批次處理，皆為空實作。

var languageSetting = this._shopDefaultAgentService.GetShopLanguageSetting(shopId);
var defaultLanguage = languageSetting.AvailableLanguages.First(i => i.Default && i.Visible);
var nonDefaultLanguages = languageSetting.AvailableLanguages.Where(i => i.Default == false).ToList();

// 預設語系：直接改欄位名稱
result.Columns[TitleMl].ColumnName = $"{TitleMl}({defaultLanguage.ShortDisplay})"; // 例：商品名稱(TW)

// 非預設語系：動態新增欄位
foreach (var language in nonDefaultLanguages)
{
    result.Columns.Add($"{TitleMl}({language.ShortDisplay})", typeof(string));    // 例：Product Name(US)
    ...
}

6. 動態欄位過濾邏輯（FilterDataTable）

根據商店設定與環境條件，部分欄位會於匯出前被動態移除：

判斷條件移除欄位對應設定來源
非全家溫層暫解商店ShippingEndDate（出貨截止日）AppSetting: Family.Temperature.LiteVersion.SupplierIds
商店未開啟「依數量拆單」IsSeparatedShopDefault: IsOrdersSplitByQty
商店未開啟「門市分批取貨」PickUpPeriodDaysShopDefault: IsEnablePartialPickup
非 PX 市場環境IsRetailStore（門市商品）AppSetting: Default.Market
商店未開放商品免稅設定TaxTypeDefDesc（商品課稅別）ShopDefault: EnableDutyFree
此方法目前於程式中定義但未在 DoProcess 主流程中被呼叫，屬於保留 / 待啟用的過濾邏輯，實際是否生效需另行確認呼叫點。

7. 例外與邊界處理

  • 儲存格內容超限：Excel 單一儲存格上限 32767 字元，超過者由 RemoveExcelOverLimitRows 移除該列，並寫入 BatchUploadMessageEntity 失敗訊息。
  • ShopId 為空：直接記錄 Log 並中止匯出（return）。
  • 無非預設語系：SetSalePageMultilingual 提前 return，不新增任何語系欄位。
  • CSV Injection 防護：依 ISupplierCustomSettingService 設定 EnableAntiCsvInjection，過濾儲存格開頭 = + - @ 字元。
  • 檔案壓縮：由 AppSetting BatchUpload.ExportDataCompression.IsEnable 控制，啟用時輸出 zip 並刪除原始檔。
