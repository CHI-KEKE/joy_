# Definition Service 呼叫鏈說明

## 核心概念

Definition Service 的唯一目的：**把 DB 存的代碼（TypeDef）自動換成可讀的描述文字（Desc）**。

資料庫為了正規化，欄位存的是代碼，例如：

| DB 欄位 | DB 值 | 使用者看到的 |
|--------|-------|------------|
| `PayProfile_TypeDef` | `CreditCardOnce` | `信用卡一次付款` |
| `Blacklist_TypeDef` | `001` | `惡意會員` |
| `ECoupon_TypeDef` | `A` | `折扣券` |

Definition 資料表就是這張**代碼字典**，`FillDefinitions` 負責自動查表並填入描述。

---

## 一、資料準備：在 Entity 上標記 `[RequireDefinition]`

```csharp
// BlacklistAllowPayProfileEntity.cs
public class BlacklistAllowPayProfileEntity
{
    // DB 存的代碼（原始值，不動）
    public string PayProfileTypeDef { get; set; }

    // 要自動填入描述的欄位，標記對應的 Table / Column
    [RequireDefinition(Table = "PayProfile", Column = "PayProfile_TypeDef")]
    public string PayProfileTypeDefDesc { get; set; }
}
```

`[RequireDefinition]` 告訴系統：
- 要去查哪張 Definition 資料表（`Table = "PayProfile"`）
- 要比對哪個欄位的代碼（`Column = "PayProfile_TypeDef"`）

---

## 二、Service 層觸發

```csharp
// BlacklistService.cs
this._definitionService.FillDefinitions(
    DatabaseEnum.WebStore,   // 指定資料庫
    payProfileList           // List<BlacklistAllowPayProfileEntity>
);
```

一行呼叫，傳入「哪個 DB」和「哪批 Entity 清單」，後面全自動處理。

## 三、完整呼叫鏈

```
Service 呼叫
    │
    ▼
FillDefinitions(DatabaseEnum.WebStore, payProfileList)
    │
    ├─ [Step 1] 將 DatabaseEnum 轉成 connectionStringName
    │           DatabaseEnum.WebStore → "NineYi.WebStore"
    │
    ├─ [Step 2] 反射掃描 Entity 的所有屬性
    │           Type dataType = GetDataType<T>();
    │           PropertyDescriptorCollection properties = ...GetProperties();
    │
    ├─ [Step 3] 找出有掛 [RequireDefinition] 的屬性，建立對應清單
    │           IEnumerable<DefinitionMappingData> mappingDatas = GetDefinitionMappingDatas(properties, dataType);
    │
    │           每筆 DefinitionMappingData 記錄：
    │             TableName        = "PayProfile"           ← 來自 Attribute.Table
    │             ColumnName       = "PayProfile_TypeDef"   ← 來自 Attribute.Column
    │             PropertyName     = "PayProfileTypeDefDesc" ← 要填值的屬性名稱
    │             PropertyDescriptor = (反射 descriptor)
    │
    ├─ [Step 4] 依 TableName 去查 Definition 資料表（有快取）
    │           foreach (TableName in mappingDatas.Select(i => i.TableName).Distinct())
    │           {
    │               GetDefinitionByTableName(connectionStringName, tableName, cleanCache);
    │           }
    │
    └─ [Step 5] 逐筆 Entity，比對代碼並填入描述
                foreach (entity in data)
                {
                    PayProfileTypeDefDesc = definitions
                        .Where(d => d.ColumnName == "PayProfile_TypeDef"
                                 && d.Code       == entity.PayProfileTypeDef)
                        .Select(d => d.Desc)
                        .FirstOrDefault();
                }
```

## 四、GetDefinitionByTableName 內部：查表 + 快取 + 多語系

```csharp
internal IEnumerable<Definition> GetDefinitionByTableName(
    string connectionStringName, string tableName, bool cleanCache)
{
    //// 快取 key 含語系，不同語系各自快取
    string cacheKey = string.Join("-", tableName, _translationClient.GetLocale());
    // 例如："PayProfile-zh-TW"

    string feature = $"Definition:{connectionStringName.Split('.').Last()}";
    // 例如："Definition:WebStore"

    //// 快取有就直接回傳，沒有才查 DB
    return CacheService.Get(..., TimeSpan.FromDays(1), () =>
    {
        //// 查 Definition 資料表
        var definitions = DefinitionRepository.GetDefinitionsByTableName(connectionStringName, tableName);

        //// 嘗試多語系替換 Desc（台灣環境找不到翻譯時直接用 DB 的 Desc）
        string module = string.Join(".", "backend.definition", tableName);
        // 例如："backend.definition.PayProfile"

        foreach (var item in definitions)
        {
            string key = string.Join("_", item.Definition_ColumnName, item.Definition_Code);
            // 例如："PayProfile_TypeDef_CreditCardOnce"

            item.Definition_Desc = _translationClient.GetString(module, key, item.Definition_Desc);
            // 台灣：找不到翻譯 → fallback 用 DB 值 "信用卡一次付款"
            // 多語系：找到翻譯 → 回傳 "Credit Card (One Time)"
        }

        return definitions;
    });
}
```

## 五、完整範例：一筆資料的完整生命週期

**Definition 資料表原始資料：**

| TableName | ColumnName | Code | Desc |
|-----------|-----------|------|------|
| PayProfile | PayProfile_TypeDef | CreditCardOnce | 信用卡一次付款 |

**Entity 查詢後（填入前）：**

```csharp
PayProfileTypeDef     = "CreditCardOnce"  // DB 查出的代碼
PayProfileTypeDefDesc = null              // 尚未填入
```

**呼叫 FillDefinitions 後：**

```csharp
PayProfileTypeDef     = "CreditCardOnce"  // 不動
PayProfileTypeDefDesc = "信用卡一次付款"   // 自動填入
```

## 六、設計目的

| 沒有這機制 | 有這機制 |
|-----------|---------|
| 每支 Service 自己寫 JOIN 查字典表 | 一行 `FillDefinitions` 搞定 |
| 新增付款方式要改程式碼 | 只需在 Definition 資料表新增一筆資料 |
| 多語系要自己處理 | 自動走 `_translationClient`，台灣 fallback DB 值 |
| 快取要自己寫 | 內建 1 天快取，含語系區分 |
