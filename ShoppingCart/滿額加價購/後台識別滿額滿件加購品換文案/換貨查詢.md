## 背景與問題

換貨處理查詢頁，加價購欄位目前一律顯示「是」，無法區分「滿額加價購」與「滿件加價購」。

**識別關鍵**：子單 `ItemType = "C"` 僅代表加購品，無法直接區分類型。  
需額外查 `SalesOrderCustomInfo` 表，透過 `JsonData` 中的 `PromotionEngineTypeDef` 欄位判斷：

| `PromotionEngineTypeDef` 值 | 意義 |
|---|---|
| `CartReachPriceExtraPurchase` | 滿額加價購 |
| `CartReachPieceExtraPurchase` | 滿件加價購 |

---

## SalesOrderCustomInfo 資料結構

```
SalesOrderCustomInfo_SourceCode  | SalesOrderCustomInfo_SourceType | SalesOrderCustomInfo_JsonData
TS260416S000012                  | CartExtraPurchase               | {"PromotionEngineId":38481,"PromotionEngineTypeDef":"CartReachPriceExtraPurchase","SpecialPriceId":229974,"ReachPrice":399.0,"ReachPiece":0}
```

- `SourceCode`：對應 TsCode
- `SourceType`：固定為 `CartExtraPurchase`
- `JsonData` 反序列化為 `CartExtraPurchaseCustomInfoJsonData`

#### 2-5. 新增 `FillCartExtraPurchaseTypeDef` 私有方法

```csharp
/// <summary>
/// 批次取得 CartExtraPurchase 活動類型（滿額/滿件），回填至子單的 CartExtraPurchaseTypeDef
/// </summary>
/// <param name="groupedEntityList">換貨單主子單清單</param>
/// <param name="shopId">商店序號</param>
private void FillCartExtraPurchaseTypeDef(
    List<MasterSlaveListEntity<SalesOrderMasterDataEntity, ChangeGoodsOrderEntity>> groupedEntityList,
    long shopId)
{
    if (groupedEntityList == null || groupedEntityList.Any() == false)
    {
        return;
    }

    try
    {
        var cartExtraSlaves = groupedEntityList
            .Where(m => m.SlaveList != null)
            .SelectMany(m => m.SlaveList)
            .Where(s => s.TradesOrderSlaveRuleTypes != null
                     && s.TradesOrderSlaveRuleTypes.Contains(nameof(SalesOrderSlaveRuleTypeEnum.CartExtraPurchase))
                     && string.IsNullOrEmpty(s.TsCode) == false)
            .ToList();

        if (cartExtraSlaves.Any() == false)
        {
            this._logger.Info($"[FillCartExtraPurchaseTypeDef] ShopId: {shopId}, 本批無 CartExtraPurchase 子單，略過");
            return;
        }

        var cartExtraTsCodes = cartExtraSlaves
            .Select(s => s.TsCode)
            .Distinct()
            .ToList();

        this._logger.Info($"[FillCartExtraPurchaseTypeDef] ShopId: {shopId}, 查詢 CartExtraPurchaseCustomInfo, TsCode 數量: {cartExtraTsCodes.Count}, TsCodes: {string.Join(",", cartExtraTsCodes)}");

        var customInfoMap = this._salesOrderCustomInfoService.GetCartExtraPurchaseCustomInfosBySourceCodes(shopId, cartExtraTsCodes);

        if (customInfoMap == null || customInfoMap.Any() == false)
        {
            this._logger.Info($"[FillCartExtraPurchaseTypeDef] ShopId: {shopId}, SalesOrderCustomInfo 查無資料, TsCodes: {string.Join(",", cartExtraTsCodes)}");
            return;
        }

        var filledCount = 0;
        var notFoundTsCodes = new List<string>();

        cartExtraSlaves.ForEach(s =>
        {
            string typeDef;
            if (customInfoMap.TryGetValue(s.TsCode, out typeDef))
            {
                s.CartExtraPurchaseTypeDef = typeDef;
                filledCount++;
            }
            else
            {
                notFoundTsCodes.Add(s.TsCode);
            }
        });

        this._logger.Info($"[FillCartExtraPurchaseTypeDef] ShopId: {shopId}, 回填完成, 成功: {filledCount} 筆, 查無 CustomInfo: {notFoundTsCodes.Count} 筆{(notFoundTsCodes.Any() ? ", TsCodes: " + string.Join(",", notFoundTsCodes) : string.Empty)}");
    }
    catch (Exception ex)
    {
        //// 查詢失敗不影響換貨處理頁主要流程，僅記錄 log，CartExtraPurchaseTypeDef 保持 null
        this._logger.Error($"[FillCartExtraPurchaseTypeDef] ShopId: {shopId}, 查詢失敗，CartExtraPurchaseTypeDef 保持 null, Exception: {ex}");
    }
}
```

### 防護設計說明

| 層級 | 防護點 | 說明 |
|---|---|---|
| 1 | `groupedEntityList == null` | 傳入 null 直接 return |
| 2 | `m.SlaveList != null` | 跳過無子單的主單 |
| 3 | `TradesOrderSlaveRuleTypes.Contains(CartExtraPurchase)` | 只處理加購品子單 |
| 4 | `string.IsNullOrEmpty(s.TsCode) == false` | TsCode 為空則略過 |
| 5 | `customInfoMap == null \|\| Any() == false` | 查無資料直接 return |
| 6 | `TryGetValue` | 逐筆安全取值，找不到保持 null |
| 7 | `try-catch Exception` | DB / 網路例外不影響換貨主查詢流程 |

> Service 層（`GetCartExtraPurchaseCustomInfosBySourceCodes`）內部已有 JSON 解析 try-catch，格式異常時 `PromotionEngineTypeDef = null`。
