# [後台][OSM][消費者訂單查詢] 標示 TS 為滿額或滿件加價購品

- **User Story**：[#604583](https://dev.azure.com/91APP/NineYi/_workitems/edit/604583)
- **Branch**：`feature/VSTS604583-消費者訂單查詢-加購品識別`（base：`VSTS564624-QA9-CartReachPriceExtraPurchase`）

---

## 背景與問題

消費者訂單查詢頁，加價購欄位目前一律顯示「是」，無法區分「滿額加價購」與「滿件加價購」。  
本次修改涵蓋兩個場景：

1. **列表顯示**（`GetOrderSlaveFlowDataList`）：回傳 `CartExtraPurchaseTypeDef` 供 FE 判斷顯示文字
2. **Excel 匯出**（`ExportOrderSlaveFlowData`）：BE 直接回填 `IsExtraDesc` 顯示文字

**識別關鍵**：子單 `ItemType = "C"` 僅代表加購品，無法直接區分類型。  
需額外查 `SalesOrderCustomInfo` 表，透過 `JsonData` 中的 `PromotionEngineTypeDef` 欄位判斷：

| `PromotionEngineTypeDef` 值 | 意義 |
|---|---|
| `CartReachPriceExtraPurchase` | 滿額加價購 |
| `CartReachPieceExtraPurchase` | 滿件加價購 |

---

## SalesOrderCustomInfo 資料結構

```
SalesOrderCustomInfo_SourceCode  | SalesOrderCustomInfo_SourceType | SalesOrderCustomInfo_JsonData
TS260416S000012                  | CartExtraPurchase               | {"PromotionEngineId":38481,"PromotionEngineTypeDef":"CartReachPriceExtraPurchase","SpecialPriceId":229974,"ReachPrice":399.0,"ReachPiece":0}
```

- `SourceCode`：對應 TsCode
- `SourceType`：固定為 `CartExtraPurchase`
- `JsonData` 反序列化為 `CartExtraPurchaseCustomInfoJsonData`

#### 2-2. 新增 `FillCartExtraPurchaseTypeDef` 私有方法

```csharp
/// <summary>
/// 批次取得 CartExtraPurchase 活動類型（滿額/滿件），回填至子單的 CartExtraPurchaseTypeDef
/// </summary>
/// <param name="groupedEntityList">消費者訂單查詢主子單清單</param>
/// <param name="shopId">商店序號</param>
private void FillCartExtraPurchaseTypeDef(
    List<MasterSlaveListEntity<SalesOrderMasterDataEntity, OrderSlaveFlowDataListEntity>> groupedEntityList,
    long shopId)
{
    if (groupedEntityList == null || groupedEntityList.Any() == false)
    {
        return;
    }

    try
    {
        var cartExtraSlaves = groupedEntityList
            .Where(m => m.SlaveList != null)
            .SelectMany(m => m.SlaveList)
            .Where(s => s.TradesOrderSlaveRuleTypes != null
                     && s.TradesOrderSlaveRuleTypes.Contains(nameof(SalesOrderSlaveRuleTypeEnum.CartExtraPurchase))
                     && string.IsNullOrEmpty(s.TradesOrderSlaveCode) == false)
            .ToList();

        if (cartExtraSlaves.Any() == false)
        {
            this._logger.Info($"[FillCartExtraPurchaseTypeDef][OrderSlaveFlow] ShopId: {shopId}, 本批無 CartExtraPurchase 子單，略過");
            return;
        }

        var tsCodes = cartExtraSlaves.Select(s => s.TradesOrderSlaveCode).Distinct().ToList();

        this._logger.Info($"[FillCartExtraPurchaseTypeDef][OrderSlaveFlow] ShopId: {shopId}, 查詢 CartExtraPurchaseCustomInfo, TsCode 數量: {tsCodes.Count}, TsCodes: {string.Join(",", tsCodes)}");

        var customInfoMap = this._salesOrderCustomInfoService.GetCartExtraPurchaseCustomInfosBySourceCodes(shopId, tsCodes);

        if (customInfoMap == null || customInfoMap.Any() == false)
        {
            this._logger.Info($"[FillCartExtraPurchaseTypeDef][OrderSlaveFlow] ShopId: {shopId}, SalesOrderCustomInfo 查無資料, TsCodes: {string.Join(",", tsCodes)}");
            return;
        }

        var filledCount = 0;
        var notFoundTsCodes = new List<string>();

        cartExtraSlaves.ForEach(s =>
        {
            string typeDef;
            if (customInfoMap.TryGetValue(s.TradesOrderSlaveCode, out typeDef))
            {
                s.CartExtraPurchaseTypeDef = typeDef;
                filledCount++;
            }
            else
            {
                notFoundTsCodes.Add(s.TradesOrderSlaveCode);
            }
        });

        this._logger.Info($"[FillCartExtraPurchaseTypeDef][OrderSlaveFlow] ShopId: {shopId}, 回填完成, 成功: {filledCount} 筆, 查無 CustomInfo: {notFoundTsCodes.Count} 筆{(notFoundTsCodes.Any() ? ", TsCodes: " + string.Join(",", notFoundTsCodes) : string.Empty)}");
    }
    catch (Exception ex)
    {
        //// 查詢失敗不影響消費者訂單查詢主要流程，僅記錄 log，CartExtraPurchaseTypeDef 保持 null
        this._logger.Error($"[FillCartExtraPurchaseTypeDef][OrderSlaveFlow] ShopId: {shopId}, 查詢失敗，CartExtraPurchaseTypeDef 保持 null, Exception: {ex}");
    }
}
```

#### 3-3. 新增 `QueryCartExtraPurchaseCustomInfoMap` 私有方法

```csharp
/// <summary>
/// 從匯出子單清單中篩出 CartExtraPurchase TsCode，批次查詢 CustomInfo Map
/// 無資料或查詢失敗時回傳空 Dictionary，不影響匯出主流程
/// </summary>
/// <param name="shopId">商店序號</param>
/// <param name="items">匯出子單清單</param>
/// <returns>Key=TsCode, Value=PromotionEngineTypeDef</returns>
private Dictionary<string, string> QueryCartExtraPurchaseCustomInfoMap(long shopId, List<OrderSlaveFlowDataExcelEntity> items)
{
    //// 從子單清單中篩出 CartExtraPurchase 類型且 TsCode 有效的子單，避免帶入空值汙染查詢
    var tsCodes = items
        .Where(i => OrderItemModeHelper.ContainMode(i.SalesOrderSlaveItemType, SalesOrderSlaveRuleTypeEnum.CartExtraPurchase)
                 && string.IsNullOrEmpty(i.TradesOrderSlaveCode) == false)
        .Select(i => i.TradesOrderSlaveCode)
        .Distinct()
        .ToList();

    //// 無 CartExtraPurchase 子單時不查 DB，節省效能
    if (tsCodes.Any() == false)
    {
        this._logger.Info($"[ExportOrderSlaveFlowData][CartExtraPurchase] ShopId: {shopId}, 本批無 CartExtraPurchase 子單，略過查詢");
        return new Dictionary<string, string>();
    }

    try
    {
        this._logger.Info($"[ExportOrderSlaveFlowData][CartExtraPurchase] ShopId: {shopId}, 查詢 CartExtraPurchaseCustomInfo, TsCode 數量: {tsCodes.Count}, TsCodes: {string.Join(",", tsCodes)}");

        var result = this._salesOrderCustomInfoService.GetCartExtraPurchaseCustomInfosBySourceCodes(shopId, tsCodes);

        //// Service 可能回傳 null（無資料時），統一轉為空 Dictionary 避免 caller 端 NullReferenceException
        if (result == null)
        {
            this._logger.Info($"[ExportOrderSlaveFlowData][CartExtraPurchase] ShopId: {shopId}, 查詢回傳 null，轉為空 Dictionary");
            return new Dictionary<string, string>();
        }

        this._logger.Info($"[ExportOrderSlaveFlowData][CartExtraPurchase] ShopId: {shopId}, 查詢完成, 取得 {result.Count} 筆");

        return result;
    }
    catch (Exception ex)
    {
        //// 查詢失敗不影響匯出主流程，IsExtraDesc fallback 為「是」
        this._logger.Error($"[ExportOrderSlaveFlowData][CartExtraPurchase] ShopId: {shopId}, 查詢失敗，IsExtraDesc 將 fallback 為「是」, Exception: {ex}");
        return new Dictionary<string, string>();
    }
}
```

#### 3-4. 新增 `ApplyCartExtraPurchaseIsExtraDesc` 私有方法

```csharp
/// <summary>
/// 依 CartExtraPurchase 活動類型回填 IsExtraDesc，非 CartExtraPurchase 子單則略過
/// </summary>
/// <param name="item">匯出 Excel 子單</param>
/// <param name="customInfoMap">Key=TsCode, Value=PromotionEngineTypeDef</param>
private void ApplyCartExtraPurchaseIsExtraDesc(OrderSlaveFlowDataExcelEntity item, Dictionary<string, string> customInfoMap)
{
    //// 非 CartExtraPurchase 子單不處理，交由上層其他邏輯決定 IsExtraDesc
    if (OrderItemModeHelper.ContainMode(item.SalesOrderSlaveItemType, SalesOrderSlaveRuleTypeEnum.CartExtraPurchase) == false)
    {
        return;
    }

    //// customInfoMap 為 null 代表查詢階段已失敗，fallback 顯示「是」，不影響主流程
    if (customInfoMap == null)
    {
        this._logger.Info($"[ExportOrderSlaveFlowData][CartExtraPurchase] TsCode: {item.TradesOrderSlaveCode}, customInfoMap 為 null，IsExtraDesc fallback 為「是」");
        item.IsExtraDesc = Translations.Backend.Service.SalesOrder.Yes;
        return;
    }

    //// 依 PromotionEngineTypeDef 判斷活動類型
    //// TryGetValue 查無對應 TsCode 時 typeDef 為 null，落入 else 顯示「是」
    string typeDef;
    customInfoMap.TryGetValue(item.TradesOrderSlaveCode, out typeDef);

    if (typeDef == nameof(PromotionEngineTypeDefEnum.CartReachPriceExtraPurchase))
    {
        //// 滿額加價購
        item.IsExtraDesc = Translations.Backend.Service.SalesOrder.CartReachPriceExtraPurchase;
    }
    else if (typeDef == nameof(PromotionEngineTypeDefEnum.CartReachPieceExtraPurchase))
    {
        //// 滿件加價購
        item.IsExtraDesc = Translations.Backend.Service.SalesOrder.CartReachPieceExtraPurchase;
    }
    else
    {
        //// typeDef 為 null（查無 CustomInfo）或未知類型，顯示「是」
        item.IsExtraDesc = Translations.Backend.Service.SalesOrder.Yes;
    }

    this._logger.Info($"[ExportOrderSlaveFlowData][CartExtraPurchase] TsCode: {item.TradesOrderSlaveCode}, TypeDef: {typeDef ?? "(null)"}, IsExtraDesc: {item.IsExtraDesc}");
}
```

## 防護設計說明

### 列表顯示（`FillCartExtraPurchaseTypeDef`）

| 層級 | 防護點 | 說明 |
|---|---|---|
| 1 | `groupedEntityList == null` | 傳入 null 直接 return |
| 2 | `m.SlaveList != null` | 跳過無子單的主單 |
| 3 | `TradesOrderSlaveRuleTypes.Contains(CartExtraPurchase)` | 只處理加購品子單 |
| 4 | `string.IsNullOrEmpty(s.TradesOrderSlaveCode) == false` | TsCode 為空則略過 |
| 5 | `customInfoMap == null \|\| Any() == false` | 查無資料直接 return |
| 6 | `TryGetValue` | 逐筆安全取值，找不到保持 null |
| 7 | `try-catch Exception` | DB / 網路例外不影響列表主查詢流程 |

### Excel 匯出（`QueryCartExtraPurchaseCustomInfoMap` + `ApplyCartExtraPurchaseIsExtraDesc`）

| 層級 | 防護點 | 說明 |
|---|---|---|
| 1 | `tsCodes.Any() == false` | 無 CartExtraPurchase 子單不查 DB |
| 2 | `string.IsNullOrEmpty(TradesOrderSlaveCode) == false` | 過濾無效 TsCode |
| 3 | `result == null` | Service 回傳 null 轉空 Dictionary |
| 4 | `try-catch Exception` | 查詢失敗回傳空 Dictionary，IsExtraDesc fallback 為「是」 |
| 5 | `ContainMode == false` guard | 非 CartExtraPurchase 子單直接略過 |
| 6 | `customInfoMap == null` guard | map 為 null 時 fallback 為「是」 |
| 7 | `TryGetValue` | TsCode 查無時 typeDef 為 null → fallback 為「是」 |

> Service 層（`GetCartExtraPurchaseCustomInfosBySourceCodes`）內部已有 JSON 解析 try-catch，格式異常時 `PromotionEngineTypeDef = null`。

## 注意事項

- **C# 語言版本限制**：專案不支援 C# 7 的 `out var` inline declaration，需先宣告 `string typeDef;` 再 `TryGetValue(key, out typeDef)`
- **Ambiguous reference 陷阱**：`SalesOrderSlaveRuleTypeEnum` 同時存在於 `NineYi.Sms.Utilities.Enums` 與 `NineYi.Sms.BL.BE.SalesOrders`，原始 SalesOrderService.cs 用的是 `BL.BE.SalesOrders` 版本，**不可新增 `Utilities.Enums` 的 using**
- **IsExtraDesc 覆蓋順序**：foreach 內的覆蓋順序為「商品加價購 → IsExtra（購物車滿額）→ CartExtraPurchase（後者蓋前者）」，`ApplyCartExtraPurchaseIsExtraDesc` 最後執行
