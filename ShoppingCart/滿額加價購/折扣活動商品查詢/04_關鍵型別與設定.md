## Dropdown Value 格式說明

前端 `<option>` 的 `value` 採用 `{PromotionTypeDef}_{PromotionDiscountTypeDef}` 格式：

```
value="CartReachPieceExtraPurchase_CartReachPieceExtraPurchase"
```

Controller 中 `GetPromotionTypeDefValue(index)` 用 `split('_')` 解析：

```typescript
public GetPromotionTypeDefValue(index: number): string {
    if (!!this.PromotionTypeDef) {
        const value = this.PromotionTypeDef.value.split('_');
        return value[index] || '';
    }
    return '';
}
// index 0 → PromotionTypeDef       = "CartReachPieceExtraPurchase"
// index 1 → PromotionDiscountTypeDef = "CartReachPieceExtraPurchase"
```

## 後端關鍵清單說明

### `queryFromN1PromotionServiceTypeList`（活動資料來源）

決定活動本身從哪裡撈：
```csharp
// 只有這一個走 MongoDB，其他全走 DB
var queryFromN1PromotionServiceTypeList = new List<string>
{
    PromotionConditionTypeEnum.AddOnsSalepageExtraPurchase.ToString()
};
```

### `queryPromotionSalepageFromN1PromotionServiceTypeList`（圈選商品來源）

決定活動的「圈選商品清單」從哪裡撈（N1 Promotion Service）：
```csharp
// CartReachPieceExtraPurchase 已在此清單中
var queryPromotionSalepageFromN1PromotionServiceTypeList = new List<string>
{
    ...,
    PromotionConditionTypeEnum.CartReachPriceExtraPurchase.ToString(),   // 滿額加價購
    PromotionConditionTypeEnum.CartReachPieceExtraPurchase.ToString(),   // 滿件加價購 ✅
};
```
