# 功能完整流程

## 流程圖

```
使用者
  │
  ▼
[Step 1] SMS 後台頁面填寫匯出條件
  │  URL：/BatchUpload/BatchSalesOrderExport
  │  View：BatchSalesOrderExport.cshtml
  │  TS Controller：batchSalesOrderExport.controller.ts
  │
  ▼
[Step 2] 前端呼叫 API
  │  POST /api/SalesOrder/CreateBatchExportDataTask
  │  Payload：ShopId, BatchUploadType, ExportCondition (時間/狀態/付款等條件), Password
  │
  ▼
[Step 3] SMS 後端建立 BatchUpload + NMQ Task
  │  SalesOrderController.CreateBatchExportDataTask()
  │    → BatchUploadService.CreateBatchExportTask()
  │        1. 建立 BatchUploadEntity (DB，狀態：Pending)
  │        2. 組裝 BatchUploadNMQDataEntity (含匯出條件、密碼 Base64)
  │        3. JSON 序列化
  │        4. 依資料量選擇 Queue：
  │           - < 1000 筆 → "BatchUpload"
  │           - ≥ 1000 筆 → "BatchUploadLarge"
  │        5. TaskHelper.CreateTask() → 推入 RabbitMQ
  │  狀態：BatchUpload → Processing
  │
  ▼
[Step 4] ScmNmq 消費處理
  │  Consumer：SalesOrderDataExportTaskProcess.cs
  │    → SCM.Frontend.BLV2.SalesOrderDataExportService.LoadData()  (讀取匯出條件)
  │    → SalesOrderDataExportRepository                             (呼叫 SP)
  │        SP：csp_BatchExportSalesOrderData (舊) / csp_BatchExportSalesOrderDataV2Sub (新)
  │    → ERP.Backend.BLV2.SalesOrderDataExportService              (填值邏輯)
  │
  ▼
[Step 5] 填值「是否為加價購品」欄位（現況）
  │  判斷邏輯：
  │    if (isAddOnsSalepageExtraPurchase && isSubItem)
  │        → 顯示「商品加價購」          (ItemType 含 "A" + "2")
  │    if (SalesOrderSlaveIsExtra == "是" or "Yes")
  │        → 顯示「購物車滿額加價購」    ← 滿額/滿件皆走這裡，無法區分
  │
  ▼
[Step 6] 產生 CSV / Excel
  │  CsvMap：SalesOrderDataExportCsvMap.cs
  │    Map(m => m.SalesOrderSlaveIsExtra).Name("是否為加價購品")
  │  狀態：BatchUpload → Completed，檔案上傳 Storage 供下載
  │
  ▼
使用者下載檔案
```

## 關鍵檔案對照

### SMS 端

| 層 | 檔案 | 說明 |
|---|---|---|
| View | `WebSite/Views/BatchUpload/BatchSalesOrderExport.cshtml` | 匯出條件表單 |
| TS Controller | `WebSite/TypeScripts/Modules/BatchUpload/batchSalesOrderExport.controller.ts` | 前端邏輯，呼叫 API |
| TS Service | `WebSite/TypeScripts/Services/salesOrder.service.ts` | `CreateBatchExportDataTask()` |
| API Controller | `WebSite/Controllers/Apis/SalesOrderController.cs` | POST endpoint |
| Business Logic | `BusinessLogic/Services/BatchUploads/BatchUploadService.cs` | 建立 NMQ Task |

### ScmNmq 端

| 層 | 檔案 | 說明 |
|---|---|---|
| Consumer | `SCM/Frontend/NMQV2/BatchUpload/SalesOrderDataExportTaskProcess.cs` | 批次任務入口 |
| SCM Service | `SCM/Frontend/BLV2/BatchUpload/SalesOrderDataExportService.cs` | 讀取條件 |
| Repository | `ERP/DA/ERPReadDBV2/Repositories/SalesOrderDataExportRepository.cs` | 呼叫 SP |
| Core Service | `ERP/Backend/BLV2/SalesOrderDataExport/SalesOrderDataExportService.cs` | **填值邏輯** |
| Entity | `WebStore/Backend/BE/BatchUpload/SalesOrderDataExportEntity.cs` | 欄位定義 |
| CsvMap | `WebStore/Backend/BE/BatchUpload/SalesOrderDataExportCsvMap.cs` | CSV 欄位映射 |
| Translation | `Core/NineYi.NMQV2.Translation/AutoGenerated/Backend.Service.SalesOrderDataExportService.cs` | 顯示文字 |

## Payload 結構

```typescript
// 前端送出
{
    ShopId: number,
    BatchUploadType: "SalesOrderDataExport",
    BatchUploadExecuteTaskType: "SalesOrderDataExportTask",
    Password: string,
    ExportCondition: {
        ShopID: number,
        SupplierID: number,
        DateTimeType: string,
        StartDateTime: DateTime,
        EndDateTime: DateTime,
        SalesOrderStatus: string,
        ShippingOrderStatus: string,
        ExportVersion: "v2",
        PayProfileStatisticsTypeDef: string,
        ShippingProfileStatisticsTypeDef: string,
        ShippingProfileDistributorDef: string,
        TemperatureTypeDef: string,
        CancelOrderSlaveCauseDef: string,
        ConfirmTypeDef: string,
        ShippingTypeDef: number
    }
}
```

## BatchUpload 狀態流轉

| 狀態 | 時間點 |
|---|---|
| `Pending` | BatchUploadEntity 建立後 |
| `Processing` | NMQ Task 被消費開始處理 |
| `Completed` | 檔案產出並上傳 Storage |
| `Failed` | 處理過程發生例外 |
