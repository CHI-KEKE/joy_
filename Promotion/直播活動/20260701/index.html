Livebuy 直播購物 — End to End 情境圖解

依目前 Web API 實作（LiveSessions / LiveComments / LiveCart / Salepage / FacebookOAuth 等 Controller），整理出「邊看邊買」與「影音回放購物」的三個典型消費者旅程，供內部溝通與規劃參考。點擊卡片查看完整流程圖與畫面示意。

邊看邊買

情境一・留言關鍵字加車

觀眾在直播留言區輸入指定關鍵字（如「+1」），系統自動辨識並加入購物車，並於留言區回覆加車成功通知。

登入 → 觀看直播 → 留言關鍵字 → 自動加車 → 留言通知 → 結帳
 邊看邊買

情境二・商品卡點選加車 / 客服協助加車

觀眾直接在直播畫面商品清單點選加入購物車；或客服／小編後台針對留言觀眾批次代為加車。

觀看直播 → 商品清單互動 → 點選 / 客服代加 → 購物車確認 → 結帳
 影音回放

情境三・直播結束後 VOD 回放購物

直播結束後系統背景轉檔產出回放影片，觀眾可於任意時間點回放並持續加入購物車下單。

直播結束 → 背景轉檔 → 取得回放網址 → 觀看回放 → 加車 → 結帳
