End to End 流程圖

sequenceDiagram
    participant HOST as 直播主播端
    participant SYS as LiveSessionsController
    participant IVS as IVS 錄製/轉檔服務
    participant U as 觀眾 (回放)
    participant FE as Livebuy 前台頁
    participant CART as LiveCartController
    participant ORD as SalesOrdersController

    HOST->>SYS: 直播結束
    SYS->>SYS: POST {liveSessionId}/sync-live-status (更新場次狀態)
    SYS->>IVS: 觸發錄製檔轉檔
    Note over IVS: 背景非同步處理，需等待數分鐘~數十分鐘
    U->>FE: 稍後開啟該場次頁面
    FE->>SYS: GET {liveSessionId}/vod?shopId=...
    alt VodUrl 尚未產生
        SYS-->>FE: VodUrl = null
        FE-->>U: 顯示「回放製作中，請稍候」
    else 轉檔完成
        SYS-->>FE: 回傳 VodUrl
        FE-->>U: 播放回放影片
        FE->>SYS: GET {liveSessionId}/products (取得當時掛載商品)
        U->>FE: 觀看回放並點選商品加入購物車
        FE->>CART: POST addSku
        CART-->>FE: 加車成功
        U->>FE: 前往購物車結帳
        FE->>ORD: POST salesorders/get
        FE-->>U: 完成結帳
    end

觀看回放 + 商品清單

GET /api/live/sessions/{id}/products

設計重點

回放機制須留意事項

  • VOD 轉檔為非同步背景作業，GetVod 回傳 VodUrl = null 屬正常情況，前端需設計「製作中」等待態，而非視為錯誤。
  • 直播中掛載的商品（products）在回放階段仍可查詢，代表商品與場次的綁定關係並非僅存在於直播當下，回放期依然能持續導購。
  • 若場次為非公開（private）頻道，需透過 playback-token 額外取得授權才能播放回放內容，用於限定會員或內購情境。
  • 回放購物的加車 / 結帳 API 與直播中「邊看邊買」共用同一套 LiveCartController / SalesOrdersController，前端購物車行為一致，不需另建流程。
