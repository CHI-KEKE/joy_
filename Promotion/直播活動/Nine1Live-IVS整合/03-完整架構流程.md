# Nine1Live × AWS IVS 完整架構流程

## 總覽

```
商家建立直播 → AWS IVS 建立頻道 → 商家推流 → 消費者觀看
     │                                              │
     └──────── 91APP LiveWebAPI 管理所有狀態 ────────┘
```

91APP LiveBuy 用 **AWS IVS 當串流基礎設施**，自己的 WebAPI 負責管理「哪個商家對應哪個 IVS 頻道」、發放播放 Token、接收 AWS EventBridge 事件來同步直播狀態，最後透過 **WebSocket** 即時通知前端。

---

## 階段一：建立直播場次

```
SMS 後台
  │
  ▼
LiveSessionsController.CreateLiveSession()
  │  Platform = Nine1Live
  ▼
Nine1LiveStreamService.CreateChannelAsync()  ──► AWS IVS API
  │                                               建立專屬頻道
  │  回傳：ChannelArn / IngestEndpoint
  │         PlaybackUrl / StreamKey (AES加密)
  ▼
DynamoDB: LiveSession.IvsChannel = { 以上資訊 }
```

- 系統呼叫 AWS IVS `CreateChannel` API
- StreamKey 以 **AES 加密**後才存入 DB
- 若綁定 `RecordingConfigurationArn`，直播會自動錄製到 S3

---

## 階段二：商家開播

```
商家 OBS / 手機 App
  │  RTMP 推流到 IngestEndpoint（帶 StreamKey）
  ▼
AWS IVS 頻道收到串流
  │
  │  AWS EventBridge 自動觸發事件
  ▼
WebhooksController.ReceiveIvsWebhook()
  │
  ▼
IvsStreamStateEventHandler
  │  event_name = "Stream Start"
  ▼
DynamoDB: LiveSession.Status = Live
  │
  ▼
WebSocket 推播給前端 → 消費者頁面顯示「直播中」
```

---

## 階段三：消費者觀看（私有頻道）

```
消費者瀏覽器
  │  GET /api/LiveSessions/{id}/playback-token
  ▼
PlaybackTokenService.IssuePlaybackToken()
  │  用 RSA / ECDSA 私鑰（P-384）以 ES384 演算法簽發 JWT
  │  JWT payload: { "aws:channel-arn": "...", "exp": ... }
  ▼
消費者拿 JWT + PlaybackUrl 播放 HLS 影片串流
  （私有頻道防盜播，Token 預設 15 分鐘有效）
```

> 若頻道 `Authorized = false`（公開頻道），消費者可直接用 `PlaybackUrl` 觀看，不需 JWT。

---

## 階段四：同步觀看人數

```
CronJob / 定時輪詢
  │
  ▼
LiveSessionsController.SyncLiveStatus()
  │
  ▼
LiveSessionService.SyncNine1LiveStatusAsync()
  │
  ▼
Nine1LiveStreamService.GetViewerCountAsync()
  │  呼叫 IVS GetStream API 取得即時觀看人數
  ▼
DynamoDB 更新：
  - CurrentViewerCount（目前觀看人數）
  - ViewerCount（最高觀看人數，只升不降）
  │
  ▼
WebSocket 推播觀看人數給前端
```

---

## 階段五：直播結束 / VOD 回放

```
AWS IVS 偵測串流中斷
  │  AWS EventBridge 自動觸發事件
  ▼
IvsStreamStateEventHandler
  │  event_name = "Stream End"
  ▼
DynamoDB: LiveSession.Status = Ended
WebSocket 推播 → 前端顯示「直播結束」

  （若有啟用錄製）
  ▼
IvsRecordingEventHandler
  │  event_name = "Recording End"
  ▼
DynamoDB: LiveSession.IvsChannel.VodUrl = S3 影片連結
  消費者可事後點播（VOD）
```
