# 例外處理與已知問題

## 已修正：ChannelNotBroadcastingException 未捕捉

### 問題描述

`GetViewerCountAsync` 呼叫 AWS IVS `GetStream` API 時，若頻道**目前沒有在直播**（offline），AWS 會拋出 `ChannelNotBroadcastingException`，但原本的 catch 只處理 `ResourceNotFoundException`，導致例外未被捕捉、往上傳遞形成大量 error log。

**錯誤訊息：**
```
Amazon.IVS.Model.ChannelNotBroadcastingException: Channel: arn:aws:ivs:... is not currently online
```

### 根本原因

IVS API 針對「頻道不存在」與「頻道未在直播」是兩個不同的 Exception：

| Exception | 觸發情境 |
|-----------|---------|
| `ResourceNotFoundException` | 頻道 ARN 根本不存在於 AWS |
| `ChannelNotBroadcastingException` | 頻道存在，但目前沒有推流（offline） |

頻道在建立後、開播前，或直播結束後的狀態都屬於「未在直播」，是**正常情況**，應回傳 `0` 觀眾數而非拋出 error。

### 修正內容

**檔案：** `BL.Services/Nine1Live/Nine1LiveStreamService.cs`

```csharp
// 修正前：只 catch ResourceNotFoundException
catch (ResourceNotFoundException)
{
    this._logger.LogInformation("頻道目前未在直播...");
    return 0;
}

// 修正後：分別處理兩種情況
catch (ChannelNotBroadcastingException)
{
    // 頻道存在但未在直播 → 正常情況，LogInformation
    this._logger.LogInformation(
        "[Ivs API] GetStream: 頻道目前未在直播，ChannelArn={ChannelArn}",
        channelArn);
    return 0;
}
catch (ResourceNotFoundException)
{
    // 頻道根本不存在 → 異常情況，LogWarning
    this._logger.LogWarning(
        "[Ivs API] GetStream: 頻道不存在，ChannelArn={ChannelArn}",
        channelArn);
    return 0;
}
```

### 影響範圍

- `SyncLiveStatus` API 定時輪詢時會大量觸發
- 修正後改為 `LogInformation`，不再產生 error/warning 噪音

## IVS 頻道建立容錯機制

`CreateChannelAsync` 若 `RecordingConfigurationArn` 無效，會**自動降級重試**（不帶錄製設定），避免整體佈建失敗：

```csharp
catch (ValidationException ex)
    when (IsRecordingConfigurationArnValidationError(ex))
{
    // 降級：移除錄製設定後重試一次
    var retryRequest = new CreateChannelRequest { ... };
    createResponse = await this._ivsClient.CreateChannelAsync(retryRequest, cancellationToken);
}
```

## Playback Token 私鑰格式相容性

`PlaybackTokenService` 支援兩種私鑰格式，啟動時自動偵測：

| 格式 | JWT 演算法 | 說明 |
|------|-----------|------|
| RSA | RS256 | 舊版格式 |
| ECDSA P-256 | ES256 | |
| ECDSA P-384 | ES384 | **AWS IVS 目前使用此格式** |
| ECDSA P-521 | ES512 | |

若兩種格式都無法匯入，啟動時直接拋出 `CryptographicException`，避免發出無效 Token。
