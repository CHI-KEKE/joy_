# 組合商品結帳資料流

## 完整路徑

```
用戶 App
  ↓
Shopping  POST /api/checkout/complete
  ↓
Cart      POST /api/checkouts/complete
  ↓  MergeRequestAndOldPayProcessContextProcessor
     ├── PayCalculate（重算折扣）
     └── CheckoutCompleteAdditional
         └── AmortizeSalepageBundleProcessor   ← 組合商品在這裡處理
             ├── 呼叫 PromotionFrontend API
             │   POST /api/amortize-by-ratio-calculate
             └── 將回傳的 additionalDiscount 寫入 salepage
  ↓
  ConvertMemberCartToWebStoreGetCart
  └── OldCartMapperService（negation 轉換）
  ↓
mweb  POST tradesOrderLite/CompleteForNewCartV2
  └── ValidateTradesOrderDataProcessor
      └── TradesOrderSlaveEntityValidator
          └── TotalDiscount <= 0 驗證
```

## OldCartMapperService Negation

檔案：`Nine1.Cart.BL.Services/OldCart/OldCartMapperService.cs`

```csharp
// lines 875-882
salePage.EngineDiscount               *= -1;
salePage.MemberTierPromotionDiscount  *= -1;
salePage.ReachQtyPromotionDiscount    *= -1;
salePage.ECouponDiscount              *= -1;
salePage.LoyaltyPointDiscount         *= -1;
salePage.LoyaltyPoint                 *= -1;
```

**設計假設：** Cart 端的折扣欄位都是正值，negation 後統一變負值給 mweb。

## mweb TotalDiscount 計算

```csharp
TotalDiscount = ReachQtyPromotionDiscount      // ≤ 0
              + MemberTierPromotionDiscount    // ≤ 0
              + PromotionDiscount              // ≤ 0
              + ECouponDiscount                // ≤ 0
              + LoyaltyPointDiscount           // ≤ 0
              + EngineDiscount                 // ≤ 0
              + AdditionalDiscount             // ⚠️ 若促購 API 回傳負值，negation 後變正值
```

## Validator 規則

```csharp
// TradesOrderSlaveEntityValidator.cs line 44
RuleFor(i => i.TradesOrderSlave_TotalDiscount).LessThanOrEqualTo(0);
```

mweb 期望 `TotalDiscount <= 0`（折扣為負數表示），若為正數則拋出 `ValidationException`。
