## 退款判斷邏輯（特殊）

2C2P 有獨特的 **IsRefund** 邏輯：退款前必須先確認訂單已 Settled，才能執行退款。

### IsQueryRefund

未 override → 預設 `false`（**不直接走 RefundQuery**）

### IsRefund（Override，特殊）

```csharp
public override bool IsRefund(..., Func<...> RefundQueryFunc)
{
    // Step 1: 先打 RefundQuery 確認訂單狀態
    var refundQueryResult = RefundQueryFunc(paytype, salesOrderThirdPartyPayment, refundRequest);

    if (refundQueryResult.ReturnCode != "00")
    {
        // RefundQuery 失敗 → 退款失敗，不繼續
        refund.ReturnCode = "RefundFailed";
        return false;
    }

    // Step 2: 確認狀態是否為 Settled（status == "S"）
    bool orderIsSettled = refundQueryResult.ExtendInfo["status"] == "S";

    if (orderIsSettled)
    {
        return true;   // 可以退款
    }
    else
    {
        // 尚未 Settled → 等待下次輪詢
        refund.ReturnCode = "RefundPending";
        return false;
    }
}
```

**流程說明：**
```
IsRefund 被呼叫
    ↓
先打 RefundQuery（查訂單狀態）
    ├── Query 失敗 → RefundFailed，本次結束
    └── Query 成功 → 看 status
            ├── status == "S"（Settled）→ return true → 執行 Refund
            └── status != "S"（未結算）→ RefundPending → 本次跳過，等下次 Job
```

> ⚠️ **2C2P 特性**：消費者刷卡後需等收單銀行「結算」(Settle) 才能退款，
> 通常需要 T+1 或數小時，期間狀態會是 Pending，由 Job 反覆輪詢直到 Settled。
