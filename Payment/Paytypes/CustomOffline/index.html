ℹ CustomOfflinePayment ≠ ATM。ATM 會透過金流商產生虛擬帳號；CustomOfflinePayment 是商家自行在後台填寫轉帳資訊，訂單建立後直接顯示給消費者，無須金流 API 介接。

Controller 回應行為

CustomOfflinePayment 不在 CompleteForNewCartV2 的任何特殊分支（LinePay、Stripe、GlobalPay 等）中， 因此會走到最後的預設回應：

// 建單成功後，回傳訂單完成結果給前端 return Json(new ApiResultEntity<object> { ReturnCode = "Success", Data = context, // 含 CustomOfflinePaymentInfo（銀行名稱、帳號等） Message = "SendTradesOrderSuccess" });
